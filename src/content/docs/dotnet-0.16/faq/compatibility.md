## Only .NET 8+? Why not .NET Framework?

Eventuous uses the latest features of C#, like records and advanced pattern matching. Therefore, we rely on recent compiler versions and the latest .NET SDK.

We also aim to support the current application hosting model, which is consistent and stable in modern .NET. Right now, Eventuous provides packages for the following runtimes:

- .NET 8
- .NET 9
- .NET 10

Targets will be added and removed when getting out of support or when new versions get released.
